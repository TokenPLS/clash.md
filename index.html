Clash

Rule-based proxy utility · powered by Hako

Clash is back, and this time it is native.

Clash gives Apple users a polished, multi-protocol, fully open-source choice. Transparency matters for software that handles subscriptions, credentials, and device traffic: the code is open to everyone, its data handling can be examined, and the community can verify its security independently.

Clash is built to fill that gap. Import your existing subscription or server configuration, then test, choose, and connect—all in one app. Clash follows your rules to decide which connections go directly and which use a proxy, keeping the whole workflow in one place.

Clash supports 21 common outbound protocol families, giving you the freedom to choose your protocol, subscription, and server. Both the client and the Hako core are fully open source, so anyone can inspect, discuss, and independently audit them. Security becomes a verifiable property.
